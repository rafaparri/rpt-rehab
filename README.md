# RPT Rehab

Aplicación web privada de seguimiento de entrenamiento: el paciente registra sus sesiones y el entrenador las revisa.

- Un único archivo: `index.html` (HTML + JavaScript, sin pasos de compilación).
- Acceso por enlace al correo (Firebase Authentication).
- Datos en Firestore (Europa). El acceso lo limitan las reglas del servidor, que se gestionan en la consola de Firebase.
- Este repositorio es público: **no contiene datos de pacientes, correos de pacientes ni el plan de entreno**.
